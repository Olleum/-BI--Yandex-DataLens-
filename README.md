📊 Проект: Система визуализации и анализа персональной статистики авиаперелетов

Репозиторий с решением кейса: «Интерактивный дашборд для анализа полетной активности в Yandex DataLens».

📌 Intro

Цель данного кейса заключалась в том, чтобы трансформировать разрозненные сырые данные об авиаперелетах в структурированный аналитический инструмент. 

Проект демонстрирует полный цикл работы BI-аналитика: от подключения источника и очистки данных до построения сложных визуализаций и формирования бизнес-выводов на основе графиков.

🎯 Задачи проекта

Data Engineering: Выполнить типизацию и очистку данных в Yandex DataLens, корректно настроив измерения (Dimensions) и показатели (Measures).

Geospatial Analysis: Настроить обработку географических координат (широта/долгота) для потенциальной визуализации на картах.

Behavioral Analysis: Проанализировать распределение мест на борту и выявить закономерности в алгоритмах авиакомпаний.

Logistics Insights: Определить ключевые транспортные узлы (хабы) и рассчитать общую интенсивность поездок (суммарный километраж).

UI/UX Design: Спроектировать финальный дашборд с удобной иерархией чартов для быстрого считывания информации.

✅ Решение

Обработка данных (ETL): Создан датасет на основе CSV, проведена настройка полей: преобразование дат (DATE), создание числовых агрегатов (DIST, NUM) и текстовых категорий (AIRLINE, AIRCRAFT).

Анализ распределения мест: С помощью круговой диаграммы (Pie Chart) выявлено аномально равное распределение (по 33% на сегменты A, M, W), что позволило подтвердить гипотезу об автоматической рассадке пассажиров.

Статистика аэропортов: Реализована линейчатая диаграмма вылетов. Лидером по количеству рейсов стал аэропорт Рощино (8 вылетов), что идентифицирует его как базовый хаб пользователя.

Калькуляция дистанций: Внедрен индикатор суммарной дистанции (DIST), рассчитывающий общий пробег всех перелетов в режиме реального времени.

Финальный дашборд: Сборка в Yandex DataLens единого интерфейса «Основное задание», включающего три типа чартов и блоки текстовой интерпретации данных.

📈 Результаты

Суммарная дистанция: Рассчитанный показатель составил 170 442 км, что эквивалентно более чем 4 кругосветным путешествиям.

Инсайт по логистике: Подтверждена высокая роль московских аэропортов (Домодедово, Шереметьево, Внуково) как ключевых транзитных узлов в структуре перемещений.

Программная реализация: Готовый интерактивный инструмент в облачной BI-системе, позволяющий мгновенно оценивать активность пассажира по различным срезам (тип судна, причина полета, регион).
